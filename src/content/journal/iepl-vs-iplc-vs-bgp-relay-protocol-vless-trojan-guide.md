## 一、线路决定下限：公网直连 vs 公网中转 vs IEPL/IPLC 物理专线

一条科学上网连接的数据包从您的设备发出，到抵达海外目标服务器（如东京的 OpenAI 机房或香港的 Netflix 服务器），按传输路径可分为三个世代：

### 1. 第一代：公网直连（野生免费梯子与廉价自建 VPS 常用）
- **路径**：您的宽带 ➔ 国际公网出口（GFW 审查墙）➔ 海外服务器。
- **致命缺陷**：数据包直接裸奔穿过国际公网出口。每晚 20:00–23:00 国际出口带宽拥塞，加上防火墙对跨境加密流量的主动探测与 QoS 限速，丢包率极高，IP 寿命往往只有几天。

### 2. 第二代：国内 BGP 公网隧道中转（传统入门机场，如 [sslar](/brands/sslar/)、[浪网](/brands/langwang/)）
- **路径**：您的宽带 ➔ 国内广深/沪杭 BGP 中转服务器 ➔ 国际公网出口 ➔ 海外落地机房。
- **特点**：因为第一跳接入了国内多线 BGP 机房，解决了电信、联通、移动跨网访问海外绕路的问题。但**过境段依然走公网国际出口**，平时速度尚可，一逢特殊敏感时期或重大节假日，仍可能出现波动。

### 3. 第三代：IEPL / IPLC 物理内网专线（2026 主力旗舰标配，如 [光速云](/brands/guangsuyun/)、[微风网络](/brands/weifeng/)、[星岛梦](/brands/xingdaomeng/)）
- **路径**：您的宽带 ➔ 国内深圳/上海机房入口 ➔ **运营商级深港/沪日内网物理专线（IEPL/IPLC）** ➔ 香港/日本内网出口 ➔ 海外原生 ISP 落地。
- **核心优势**：IEPL（International Ethernet Private Line，国际以太网专线）与 IPLC（国际私有租用线路）本质上是跨国企业银行、证券机构租用的点对点内网光纤通道。**它完全不经过拥堵的公网国际出口，也不受常规公网 GFW 流量清洗干扰**。因此，深港 IEPL 的过境延迟通常仅有 **2ms–5ms**，即便在除夕夜或晚高峰黄金时段，4K/8K 视频依然能够秒开。

## 四、新兴协议辨析：Hysteria2 与 TUIC v5 为什么在专线上并非必需？

近年来，基于 UDP / QUIC 协议栈开发的新型协议——**Hysteria2（歇斯底里 2）** 与 **TUIC v5** 在自建圈和部分廉价机场中声名鹊起。很多新手误以为“协议版本号越新就一定越高级”，事实并非如此简单。

### 1. Hysteria2 的本质：劣质公网上的“带宽强盗”
Hysteria2 采用了激进的拥塞控制算法（Brutal Congestion Control）。它的核心理念是：在公网国际出口丢包率高达 20%–40% 的恶劣直连线路上，不理会丢包直接成倍多发冗余 UDP 包，强行霸占信道把带宽拉满。
- **优点**：能够把原本只有 10Mbps 的垃圾公网线路在白天测速时压榨出 200Mbps。
- **副作用**：
  - **严重发热与耗电**：持续的大流量 UDP 包加解密会让手机 5G 基带芯片迅速发烫，电池消耗速度比 TCP 协议快 30%–50%。
  - **运营商 QoS 封锁**：国内三大运营商（尤其是移动与晚高峰电信）对大流量 UDP 端口管控极严，连续跑几分钟就会遭遇运营商路由器的临时断流惩罚。

### 2. 为什么优质 IEPL 专线坚持使用 VLESS / Shadowsocks？
因为在 **[光速云](/brands/guangsuyun/)** 与 **[微风网络](/brands/weifeng/)** 的 IEPL 物理内网专线上，过境段丢包率本来就接近于 **0.00%**！在零丢包的纯净内网中，基于 TCP 的 **VLESS (XTLS-Reality)** 与 **Shadowsocks 2022** 的协议开销只有几个字节，握手时间不到 20 毫秒，既能跑满万兆带宽，手机全天后台挂机又极其省电、温度清凉。

## 五、物理光速极限与节点 RTT 算账：别被 5ms 假延迟欺骗！

很多小白在客户端里看到某个香港节点显示 `5ms`，以为自己连到了真正的香港，这其实是典型的**「入口延迟欺骗（Entry Latency）」**。

### 1. 真实端到端延迟的计算公式
一个真实的数据包完整往返时间（RTT）应为：
$$\text{总延迟} = \text{本地至国内入口延迟} + \text{国内过境专线延迟} + \text{海外落地出口延迟} + \text{海外目标服务器响应延迟}$$

### 2. 物理光纤传播极限（光在玻璃介质中的光速约为 20 万公里/秒）
- **深港内网专线（深圳 ➔ 香港）**：物理距离约 40 公里，过境光纤单程传输仅需约 0.3ms，往返算上交换机排队约 **2ms–5ms**。若加上您在省内的接入，珠三角用户到香港服务器真实 RTT 约为 **15ms–28ms**；北方或内陆用户约为 **35ms–55ms**。
- **沪日内网专线（上海 ➔ 东京）**：物理海缆往返极限约 **24ms–28ms**，全国平均真实 RTT 在 **45ms–75ms**。
- **广新内网专线（广州 ➔ 新加坡）**：全国平均真实 RTT 在 **40ms–65ms**。
- **中美直达跨洋链路（上海/广州 ➔ 洛杉矶）**：跨越太平洋物理距离超 1 万公里，光缆往返物理极限约为 **125ms**！因此任何真实连接到美国机房的节点，延迟绝不可能低于 130ms。

如果客户端里显示的美国节点只有 20ms，说明该软件只是测了你到国内入口机房的距离，并没有测试真实出境访问的连通性！在 [42家机场评测库](/brands/) 中，我们坚持采用端到端真实测试，坚决杜绝虚标误导。

## 六、DNS 防污染关键：为什么推荐开启 Fake-IP 模式？

科学上网时经常遇到「国内微信正常、外网却打不开」或「DNS 严重泄露导致 Google 搜索定位到中国」，核心在于客户端的 DNS 策略选择。

### 1. Redir-Host（传统模式）的缺陷
客户端在本地拦截到域名请求后，必须先等待真实 DNS 服务器返回一个海外 IP，再比对该 IP 是否在大陆白名单内。这不仅增加了 30ms–100ms 的 DNS 递归解析等待时间，而且极易遭受本地运营商的抢答污染。

### 2. Fake-IP（增强模式）的秒级响应优势
当您启用 Clash Verge Rev 的 `enhanced-mode: fake-ip` 时：
1. 浏览器请求 `www.youtube.com`，客户端在 0.1 毫秒内瞬间返回一个虚拟保留内网地址（如 `198.18.0.12`）。
2. 浏览器立即发起连接，客户端把虚拟 IP 还原为原本的域名字符，直接封装进 **[光速云](/brands/guangsuyun/)** 的 IEPL 专线隧道，由香港/日本海外落地服务器在机房本地完成最终解析。
3. 这种机制不仅消除了 DNS 解析等待时间、网页打开快如闪电，更在物理层面上 100% 免疫了国内运营商的 DNS 劫持与位置泄漏。配合本站提供的防 DNS 污染覆写配置，能获得最纯净的网络体验。
